# suewheeler-web

Marketing website for **Wood Refinishing by Sue Wheeler** — St. Louis, MO.

## Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS v4
- **Components:** Shadcn/Radix
- **Database:** Neon Postgres + Drizzle ORM
- **Auth:** NextAuth
- **Storage:** AWS S3
- **Deploy:** Vercel

## Structure
```
src/          Next.js app source
public/       Static assets
docs/         Design spec, style guide, component patterns
```

## Design Reference
Design mockups live at `../designs/active/` (Option 2 from Variant.com).
These move to `../designs/_archive/` once the site is built.
The canonical design spec is `docs/design-spec.md`.

## Getting Started
```bash
pnpm install
pnpm dev
```
