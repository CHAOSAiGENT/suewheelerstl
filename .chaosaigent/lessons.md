# Lessons — suewheelerstl

- 2026-06-14: Run steering verify at session START (`/chaos-controller steer`) — it would have surfaced the Supabase MCP access gap before the migration attempt, not during it.
- 2026-06-14: Before scoping a dependency bump as "major/breaking", read the INSTALLED version, not the audit advisory's vulnerable-range string. The Next.js "high-sev upgrade" was actually a patch (15.5.14→15.5.19).
- 2026-06-14: For monitors, exercise the REAL path (same table/columns), not a proxy/heartbeat table — a separate-table health check would have passed green while the actual contact form 500'd.
- 2026-06-14: Deploy ordering for schema-coupled changes — apply the migration to live DB BEFORE pushing code that contracts the new column, or the schema-drift CI gate goes red and the endpoint 500s.
- 2026-10-10: Verify the EFFECT, not the artifact. A denial/gate/hook is not enforced until something *observably stops happening*. Writing an entry and reading it back proves only that the file was written. Three config failures in one session all reported success while doing nothing — the same shape as `ADMIN_EMAILS` dead for 166 days, a monitor green while the form 500'd, and a leak check that passed on failure.
- 2026-10-10: Never put an absolute path in a config file. The repo moved from `CHAOS/CLIENT_SITES/` to `CHAOS/_clients/client_sites/` and two hooks died with no alarm, because `cd <missing> && cmd; exit 0` short-circuits and then reports success. Use `"$CLAUDE_PROJECT_DIR"` and make the misconfiguration path write to stderr.
- 2026-10-10: `deniedMcpServers` matches the user-assigned label VERBATIM (`claude.ai Canva`, not `Canva`; `plugin:context7:context7`, not `context7`; `agentation`, not `agentation-mcp`). A mismatch fails silently. Run `claude mcp list` and copy the label; prefer `serverUrl`/`serverCommand`, which survive a rename.
- 2026-10-10: `skillOverrides` does NOT reach plugin skills (anything colon-prefixed, e.g. `posthog:*`). Writing the key succeeds, the skill stays loaded, and the report is false. Plugin skills need `/plugin` or `enabledPlugins` — which is all-or-nothing, so "keep only the core N of this plugin's skills" is not expressible.
- 2026-10-10: Read a setup/sync script before running it. `chaos-controller`'s `sync_registry_to_settings()` rebuilds `deniedMcpServers`/`skillOverrides` wholesale from `grep "^### "` — the registry's denied section had been reformatted as a table, so a `setup` run would have written `[]`/`{}` and wiped 15 working denials with no error.
- 2026-10-10: Do not read a command's exit code through a pipe. `cmd | sed; echo $?` reports *sed's* status — it briefly made a working `.env` blocker look like it was exiting 0 and not blocking. Capture output to a variable, then check `$?`.
- 2026-10-10: Keep the decision log level with the architecture. `DECISIONS.md` stopped at D36 while seven significant choices shipped; their reasoning survives only in commit bodies and plan files, which is not where anyone looks for a decision.
